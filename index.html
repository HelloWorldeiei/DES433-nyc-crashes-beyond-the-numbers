Data source, methodology & limitations +

Data source and coverage

New York City Open Data — Motor Vehicle Collisions — Crashes. The dashboard covers all recorded collisions in 2013–2025; one crash report is one event. Filters affect all seven visualizations.

Changes in reporting practices

NYPD altered non-injury collision reporting in April 2020, while the pandemic changed travel patterns. Total reported crashes before and after 2020 are not fully comparable. The data do not provide trips, driving distance or population denominators.

Definitions and indexed comparisons

Indexed trend = annual metric / same region's 2019 metric × 100. Each actual-value view uses only one outcome scale. Injury-involved percentage divides crash reports with at least one injured person by reports with known injury status. Missing injury status is not assumed to be zero.

Geographic analysis

The map can switch between all reports, reports with at least one injured person, and reports with at least one killed person. Those categories can overlap. The density map shows records with usable geographic coordinates only. All other charts retain records with missing coordinates. The map uses a locally rendered, single-hue sequential color scale for each selected outcome, with a fixed geographical extent and color scale across animation frames. Each dot represents a regular spatial bin, not an individual crash. Colour intensity is log-scaled by count per bin. The approximate borough outlines are derived from geocoded records and are not official administrative boundaries. No map tile service or API key is required.

Day and hour

Crash reports are grouped into 168 weekday–hour combinations. Bubble area represents the selected value, while the seven-step color legend emphasizes differences within the current filter selection. For the percentage view, the denominator includes only reports with known injury status. Color ranges can change when filters change; neither crash totals nor injury-involved percentages are adjusted for traffic exposure.

Vehicle combinations

The heatmap uses the first and second recorded vehicle types as unordered pairs. Car, SUV / Van, Taxi / Rideshare, Truck, Motorcycle / Moped, Bicycle and Bus appear individually; Emergency, Commercial / Other and Other are consolidated into “Other types” for display (not discarded). Each crash contributes at most one pair. Only the upper triangle is shown, so mirrored combinations are not counted twice. Missing/unclassified types can be included as Unknown. Third and later vehicles are not represented.

Missing values and contributing factors

Unknown boroughs are not a sixth borough. They are excluded from the five-slice donut, displayed separately with the relevant citywide percentage, and remain in citywide totals. The donut can switch between shares of crash reports and shares of injury-involved crash reports; these are additive counts, NOT borough injury rates or exposure-adjusted risk.

A known factor is counted once per crash, even if it appears in both first and second factor fields. The separate gray “Both Unspecified” data-quality item counts only reports where both fields explicitly say Unspecified. This preview's browser aggregates were rebuilt from the original NYC source export; the selected MN Parquet is included in the editable package for regenerating matching group classifications with the build script and a Parquet reader.
